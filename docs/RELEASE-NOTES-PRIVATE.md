# 0.1.0-draft — MIT source preview

Contains two source utilities: fixed PCR-bank capability capture and ephemeral RSA2048/RSASSA-SHA256 claim capture with caller-supplied nonce. No trusted enrollment or server integration is implemented.

Validation: isolated direct Windows build/resource compile, 38 portable test cases, and offline static PE review passed. Linux portable tests previously passed 38 cases. Helper execution, CMake execution, signed distribution compatibility and production attestation are not verified.

MIT is active for these project sources. Sources are published at https://github.com/hakanbasatici/tpm-evidence-tools. No binary release has been published and no signing-provider sponsorship is claimed. Test binaries are not proposed user-distribution artifacts. No EXEs are included in this source package.
