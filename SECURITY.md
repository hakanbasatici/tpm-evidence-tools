# Security reporting

Use GitHub private vulnerability reporting: [Report a vulnerability](https://github.com/hakanbasatici/tpm-evidence-tools/security/advisories/new). The repository owner enabled this channel on 2026-10-15, confirmed by the settings screen. No test report has been submitted and notification delivery has not been tested.

Maintainer: @hakanbasatici. Do not post security vulnerability details, private keys, nonce/session values, certificates, boot logs or device outputs in public issues. Include only the minimum necessary redacted evidence in a private report. No response-time SLA is promised for this source preview.

Treat this as diagnostic source, not a trust authority. A saved quote is not fresh attestation. An ephemeral public key is not trusted enrollment. Report parsing and validation failures without lowering the verification profile.
