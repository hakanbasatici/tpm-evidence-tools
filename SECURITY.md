# Security reporting

Do not publish private keys, nonce/session values, certificates, boot logs or device outputs in public issues. A private vulnerability-reporting channel has not yet been configured. Maintainer: @hakanbasatici. Do not disclose vulnerability details in public issues. A generic request to establish private contact may be opened without sensitive details. No private email address or working advisory channel is claimed. This gap must be resolved before a supported binary release.

Treat this as diagnostic source, not a trust authority. A saved quote is not fresh attestation. An ephemeral public key is not trusted enrollment. Report parsing and validation failures without lowering the verification profile.
